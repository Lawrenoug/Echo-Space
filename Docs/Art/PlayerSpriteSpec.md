# Echo Space 玩家角色像素帧动画规范

这份文档用于约束玩家角色的像素帧动画制作方式，保证后续生成的角色素材能直接服务于 Godot 的 `AnimatedSprite2D` 或 SpriteFrames 工作流。

## 1. 结论

- 不修改玩法和叙事策划核心。
- 不把“现实世界角色”和“灵魂世界角色”混在同一张角色设计里。
- 角色美术执行改为“像素风角色分支”，先验证玩家角色与核心动作，再决定是否把敌人、特效和 UI 一并像素化。

## 2. 为什么适合像素风

- 当前项目已经开启 `2d/snap/snap_2d_transforms_to_pixel=true` 和 `2d/snap/snap_2d_vertices_to_pixel=true`，Godot 层面对像素帧动画是友好的。
- 当前主角碰撞体接近 `22x34`，很适合映射为一套紧凑的像素角色尺寸。
- 横版动作游戏的待机、跑动、攻击、防御、受击等状态，用像素逐帧做节奏感会更直接。

## 3. 风格边界

- 角色采用像素风。
- 现实世界版和灵魂世界版必须是两套独立角色外观，而不是一张图里左右拼接或半透明叠加。
- 保留原策划中的气质关键词：
  - 现实世界：赭石、锈蚀金属、裂石、深木色、可触摸、有重量。
  - 灵魂世界：幽蓝、紫灰、发光边缘、半透明感、空间不稳定。
- 虽然转成像素风，但不能变成可爱 Q 版，也不能变成日系大头身。

## 4. 角色基准

- 推荐单帧画布：`48x64`
- 推荐角色实际站立高度：`40px` 到 `46px`
- 朝向：严格侧视，统一朝右出图
- 基准地面对齐：所有动作脚底落在同一水平线
- 导出背景：纯色底，便于后续抠图或统一转透明

## 5. 双世界角色拆分

### 5.1 现实世界版

- 轮廓关键词：清晰、结实、偏人类实体感。
- 服装关键词：破损短斗篷、轻甲片、绑带护臂、旧靴、仪式直剑。
- 配色关键词：炭黑、蓝灰、锈橙、暗红棕。
- 发光限制：只能有非常少量的余烬裂痕或金属反光。

### 5.2 灵魂世界版

- 轮廓关键词：更轻、更飘、更尖锐。
- 服装关键词：保留同一人物识别点，但边缘更碎裂，布料更像被灵体拉扯。
- 配色关键词：深蓝、紫灰、冷青、苍白高光。
- 表现限制：可以有微弱残影感，但角色主体仍必须是单体、完整、可读的像素人形。

## 6. 动作拆分建议

第一批先做原型最需要的核心动作：

1. `Idle`
2. `Run`
3. `JumpStart`
4. `Fall`
5. `Guard`
6. `Parry`

第二批再补：

1. `Attack`
2. `Hurt`
3. `Dead`
4. `Execute`

## 7. 每个动作的逐帧要求

### 7.1 Idle

- 推荐帧数：6
- 目标：呼吸、布料轻晃、持剑手微调、重心轻微切换
- 禁止：站姿每帧差异过大，看起来像抽搐

### 7.2 Run

- 推荐帧数：8
- 目标：前倾明显、摆臂清晰、斗篷与下摆跟随、脚步接触点明确
- 禁止：脚底漂浮、躯干完全不动

### 7.3 JumpStart

- 推荐帧数：3
- 目标：下压蓄力、抬臂或收剑、脚踝压缩后释放
- 禁止：直接把待机姿势抬高冒充起跳

### 7.4 Fall

- 推荐帧数：2 到 3
- 目标：身体拉长、衣摆下坠、武器位置稳定
- 禁止：和起跳姿势几乎一样

### 7.5 Guard

- 推荐帧数：3
- 目标：重心降低、剑或手臂形成防线、姿态偏稳
- 禁止：看起来像普通待机

### 7.6 Parry

- 推荐帧数：4
- 目标：短促爆发、前臂和武器快速外拨、节奏比 Guard 更锐利
- 禁止：做成大幅攻击动作

### 7.7 Attack

- 推荐帧数：5 到 6
- 目标：前摇、出刀、命中延展、收刀完整
- 禁止：从第一帧就直接命中

### 7.8 Hurt

- 推荐帧数：3
- 目标：上身后仰或收缩、重心失衡、痛感明显
- 禁止：只改表情不改肢体

### 7.9 Dead

- 推荐帧数：5 到 6
- 目标：失力、下坠、倒地
- 禁止：最后停在站立姿态

### 7.10 Execute

- 推荐帧数：6
- 目标：短冲、定点、重斩、收势
- 禁止：动作幅度太小，缺乏终结感

## 8. 生成规范

- 每张图只做一个动作，不混多个动作。
- 每张图只做一个世界版本，不混现实和灵魂版本。
- 每张图内使用统一角色比例和统一地平线。
- 每帧之间保留足够空白，方便切片。
- 优先使用横向动作条带或规整网格，方便导入 Godot。
